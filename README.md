# English Cards — приложение для изучения английского

Flutter-приложение с карточками слов. Карточка переворачивается по нажатию
вокруг вертикальной оси (3D-анимация), показывая перевод на обратной стороне.

## Структура проекта

```
lib/
  main.dart                     — точка входа, тема оформления
  models/flash_models.dart      — модели WordCard и WordCategory
  data/sample_data.dart         — тестовые данные (5 категорий слов)
  widgets/category_tabs_bar.dart— горизонтальные вкладки категорий
  widgets/flip_card_widget.dart — карточка с анимацией переворота
  screens/home_screen.dart      — главный экран (список слов)
  screens/cards_screen.dart     — полноэкранный просмотр карточек (PageView)
```

## Запуск

1. Установите Flutter SDK: https://docs.flutter.dev/get-started/install
2. В папке проекта выполните:
   ```
   flutter pub get
   flutter run
   ```
3. Для сборки под Android/iOS: `flutter build apk` или `flutter build ios`

## Как это работает

- **Переворот карточки** реализован через `Matrix4.rotateY()` внутри
  `AnimatedBuilder` (файл `flip_card_widget.dart`). Перспектива
  (`setEntry(3, 2, 0.0015)`) делает переворот объёмным, а не плоским.
- **Горизонтальный скролл категорий** — обычный `ListView` с
  `scrollDirection: Axis.horizontal`.
- **Скролл карточек** на экране просмотра — `PageView.builder`, каждая
  страница шириной в экран (минус отступы), поддерживает любое количество
  карточек.
- **Данные** вынесены отдельно (`sample_data.dart`), поэтому легко заменить
  на загрузку из API или локальной базы (например, sqflite/Hive).

## Озвучка слов (TTS)

Подключён пакет `flutter_tts`. Иконка динамика на лицевой стороне
озвучивает слово, на обратной — пример предложения на английском.
Настройки голоса (язык `en-US`, скорость, тон) заданы в
`_setupTts()` внутри `flip_card_widget.dart`.

Android/iOS используют системный синтезатор речи — дополнительная
настройка не требуется, но для Android иногда нужно, чтобы в
системе был установлен голосовой движок Google (обычно уже есть
по умолчанию).

## Возможные доработки

- Сохранять прогресс изучения (например, через `shared_preferences`).
- Добавить экран настроек (шестерёнка в шапке пока декоративная).
- Дать пользователю выбор голоса/скорости озвучки.
